## 1. §3-5-6 — 추론 계획 사전등록 (`e98ccce`)

GPT 9/13 수정이 `passed = set()` 으로 승인을 전면 보류한 이유가 "겹침·반복검정 계획
미확정"이었다. 그 계획을 **결과와 독립적으로** 정한 것이 이 절이다.
**절차를 원장에 한 번도 돌리지 않은 채 커밋했다.** 돌려 보고 여는 것은 결과를 보고 여는 것이다.

| 문제 | 처리 |
|---|---|
| 겹친 보유기간 | 이동블록 부트스트랩. **블록 길이 = H** — 고르는 값이 아니라 설계가 정한다. 재표본 10,000 · 시드 20260913 · `(초과+1)/(재표본+1)` |
| 반복검정 | 결정일 **4회 상한**(10/05 · 2027-01-05 · 04-05 · 07-05), 결정일당 `α=0.0125`, 그 안에서 Holm(m=2) |
| 재현 창 | "1차 달성일로부터 4주" → **달력 고정 블록 A/B/C** (시작일이 자료와 무관해진다) |
| 정책 동결 | 블록 안에서 `POLICY_SINCE` 가 움직이면 그 블록 무효 |

자기검증이 문제를 직접 보여 준다 — **같은 정보를 행 수만 2배로** 늘리면:

| | t 단측 p | 블록 부트스트랩 p |
|---|--:|--:|
| 6개 값 × 5행 | 0.0110 | 0.0283 |
| 6개 값 × 10행 | **0.0005** | 0.0275 |

정보는 안 늘었는데 t 는 20배 유의해진다. 부트스트랩은 움직이지 않는다.

**`passed` 는 비워 둔 채로 뒀다.** 기계는 만들었지만 GPT 의 보류를 내가 일방적으로
풀지 않는다. 언제 푸는지는 GPT 판단이 필요하다(→ 일정표 6절 항목 1).

### 검사 두 개를 버렸다

- "부트스트랩이 t 보다 **3배 이상** 보수적" → 실제 2.6배. **내가 정한 임의 배수**였다
- "독립 블록이 적을수록 격차가 커진다" → 2.0 vs 2.6 으로 **반대**가 나왔다

문턱을 낮춰 통과시키는 대신 **검사를 버리고**, 유도되는 성질(가짜 N 에 안 속는다)로 바꿨다.

`T+1 종가` 한 줄만 바꿨다. 다른 줄까지 같이 손대면 그게 재설계다.

## 3. 종베 분석기 신설 — `hyeoks_closing_bet.py` (`adc4f06`)

### 3-1. 무엇을 재나

15:05 슬롯 `nowPrice` 진입 → **익일 시가 전량 청산**. 오후수급 비율
(`tradeAmount(15:05) / tradeAmount(13:00)`) 5분위 중 **Q5 하나**를 유니버스 전체
등가중 평균과 비교한다. 표본 단위는 **거래일**.

**익일 시가는 다음 거래일 스냅샷의 `openPrice`** 로 얻는다. 같은 날 13시·15:05 두
슬롯의 `openPrice` 가 **31,573/31,628 = 99.83%** 일치해서 네트워크가 필요 없다.
불일치 0.17% 는 13시 값을 쓰고 건수를 보고한다.

### 3-2. 🔒 단계 잠금 — 이게 핵심이다

| 단계 | 조건 | 산출 |
|---|---|---|
| **0** | 성숙일 < 20 | 수집·품질·탈락만. **수익률 필드를 만들지조차 않는다** |
| **1** | ≥ 20 | σ·자기상관·필요 N 만. **평균·t·p 출력 금지** |
| **2** | ≥ 20 + 본 구간 | ①·② 와 HAC(지연 5) 판정 1회 |

`'계산은 해 두고 안 보여주기'는 장치가 아니다 — 계산하면 결국 본다.` 그래서 단계 0
에서는 `with_returns=False` 로 수익률을 아예 만들지 않고, **자기검증이 결과 dict 에
`rel` 키가 없는 것을 직접 확인한다.** 단계는 데이터가 정하며 **플래그로 건너뛸 수 없다.**

**오늘 첫 실행 결과: 성숙 10일 / 20일 — 수익률을 계산하지 않았다.**
(스냅샷 11거래일 · 유니버스 하루 367종목 · 백업 cron 발사분 0일 · 중복 0 · 동률 0)

### 3-3. §6-12-6 — 미정 항목을 결과 못 본 상태에서 전부 닫았다

§6-12-3 이 "성과 열람 전 확정 필요"로 남긴 셋 + 9/9 보완이 "본 구간 전에 확정"이라
적은 셋을 닫았다.

| 항목 | 확정 |
|---|---|
| 분석 유니버스 | 정의1 ∩ {비율 계산 가능} ∩ {익일 시가 붙음}. **비율 불가 종목은 대조군에서도 뺀다** — Q5 에 뽑힐 수 없는 종목이 대조군에만 남으면 대조군이 'Q5 를 뽑은 모집단'이 아니게 된다 |
| 분위 동률 | 순위 기반 `⌊5·rank/n⌋` + **종목코드** tiebreak. 결과와 무관한 값으로만 깬다 |
| 분위당 최소 | **10종목**(일 유니버스 50 미만이면 그날 버림). 실제 367종목이라 거의 안 걸린다 — **거의 안 걸리는 규칙이라서 좋은 규칙이다** |
| 거래대금 역전 | 제외. 누적값은 줄어들 수 없다 |
| 중복 종목행 | **먼저 나온 행**을 남기고 센다 |
| 기업행사 | 검사 둘 ↓ |
| 달력 | 빠진 거래일을 이웃으로 붙이지 않는다. `nontrading.txt` 로만 완화 |
| 본 구간 | `min(max(ceil(필요N), 40), 120)`, σ̂ = **HAC 장기표준편차** |

#### 기업행사 검사 둘 — A 로는 못 잡는다

익일 스냅샷에서 전일종가를 되돌린다: `C_prev = nowPrice / (1 + prevChangeRate/100)`.

| 검사 | 조건 | 잡는 것 |
|---|---|---|
| A. 거래소 규칙 | `abs(익일시가 / C_prev − 1) > 30.5%` | 익일 시가 자체가 이상 |
| B. 기준가 축 | `abs(C_prev / 진입가 − 1) > 35%` | **무상증자·액면분할·병합** |

조정일에는 거래소가 기준가도 같이 조정하고 `prevChangeRate` 도 **조정된 기준가** 대비로
오므로 **A 는 통과한다.** 어긋남은 우리 진입가와 익일 기준가 사이에 나타나고 B 가 잡는다.
자기검증에 액면분할 5:1 사례를 넣어 **A 통과 · B 적발**을 고정했다.

⚠️ B 는 극단적 장중 반전을 오탐할 수 있다. 그 비용을 받아들이는 이유는, 놓치면
±100%짜리 허수 수익률이 일별 평균을 통째로 흔들기 때문이다. 건수를 보고한다.

#### 이중 차감 검사 (§6-12-5 가 요구한 것)

처음에 "소스에 `close_drift` 문자열이 있는가"로 짰다가 **자기참조**라 항상 실패했다
(검사 코드 자체에 그 문자열이 있다). 바꿨다 —

> 진입가 1000 · 그날 종가 1100 · 익일 시가 1100 → 수익률이 **0% 가 아니라 +10%** 인가

종가 이동분을 또 빼는 구현이면 `(1100−1100)/1000 = 0%` 가 나온다.
