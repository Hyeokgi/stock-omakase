# 시간외 시장·등락률 표시 교정

## 근거와 변경

9/14 17:35 네이버 basic 응답에서 삼성화재의 closePrice와 overPrice가 모두
672,000원이었다. generic overMarketPriceInfo는 AFTER_MARKET이지만 거래소는
명시하지 않았다. 기존 스캐너는 이를 NXT로 간주하고 두 현재가격의 차이로
0.00%를 계산했다. 이 숫자는 오늘 정규장 종가 대비 등락률이 아니다.

- 스캐너는 같은 HTTP 응답의 가격·전일대비·시각을 함께 사용한다. TLS와 HTTP 상태도 확인한다.
- generic 필드는 `시간외(시장 미확인)`으로 표시한다. NXT/ KRX 가격을 추정하지 않는다.
- 제공처 전일종가 대비 등락률은 가격·전일 대비 차이와 산술 일치할 때만 표시한다.
- 오늘 정규장 종가를 인증하는 별도 소스는 아직 없으므로 `정규장종가 대비 미확인`이다.
  현재가나 출처가 불명확한 당일 일봉을 정규장 확정 종가로 대신하지 않는다.
- 시세 시각을 기록한다. 다른 날짜·시각 없음·미래 시각·세션 불일치는 미확인,
  당일 10분 초과 관측은 지연 표시한다. 지연은 무거래와 전송 지연을 구분하지 못한다.
- 보조 시트 AA/AB, 스캐너 Q/R 제목은 관측값으로 변경한다. 열 위치는 유지한다.
- 갱신하지 못한 스캐너 보존행은 이전 NXT/시간외 수치 대신 미확인으로 바꾼다.
- nightly의 현재가 분모 폴백도 제거했다. 기존 제공처 등락률은 기준 미검증으로 표시한다.
  nightly의 거래소별 인증·체결시각은 아직 독립 검증하지 않았다.

## 검증과 한계

오프라인 unittest 202개 통과(Windows UTF-8 출력 설정). 신규 시험은 generic의 NXT
오분류 방지, 날짜/세션 검증, 누락/불일치 등락률, 진짜 0%, 지연, 실제 스캐너 연결을 다룬다.
네이버 실응답 읽기만으로도 파서 출력을 확인한다. 테스트 성공과 시트 배포 성공은 구분한다.

이 변경은 잘못된 확신을 없애는 보수적 교정이다. 거래소별 가격·오늘 정규장 종가를
확인한 완전한 시간외 수익률 계산기까지 완성한 것은 아니다. 기존 시트의 과거 잘못된
관측값을 소급 인증하지 않으며, 앱 자체의 고정 시장명 UI는 별도 확인 대상이다.
전략·15:05 진입·익일 시가 청산·추천 문턱·원장 수익률 계산은 변경하지 않았다.
다음 스캐너 실행부터 새 표시를 작성하도록 코드를 반영한다. 수동 전체 스캔이나
유료 AI 호출·실제 주문은 이 검증에서 실행하지 않는다.
