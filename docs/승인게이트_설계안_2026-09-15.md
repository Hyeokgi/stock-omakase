# 🚪 승인 게이트 설계안 — 트랙이 하나가 아니다

작성 2026-09-15 (Claude) · **설계안이며 구현 전이다.** 코드는 아직 바뀌지 않았다.
계기: ChatGPT 교차검증 지시서(`7759054` 기준) P0-2·3·4·5
대상 합의자: ChatGPT · 사용자

> ⚠️ **이 문서는 새 기준을 만들지 않는다.** 이미 사전등록된 절차를 **코드가 실행할 수
> 있는 형태로 옮기는 것**이 전부다. 사전등록에 없는 것은 '미정'으로 표시하고
> 별도 합의를 요청한다. 여기서 몰래 정하지 않는다.

---

## 0. 왜 이 문서가 먼저인가

ChatGPT 지시서 P0-4 는 이렇게 요구한다.

> 결정일이 아닌 실행에서는 어떤 p-value 가 나오더라도 `passed == set()` 이어야 한다.

**확증 채널에는 맞는 요구다. 그런데 그대로 단일 게이트로 구현하면 사전등록을 어긴다.**

사전등록은 승인 경로를 **셋**으로 나눠 놓았고, 일정도 문턱도 서로 다르다.
하나로 합치면 둘 중 하나가 일어난다.

| 잘못 합쳤을 때 | 결과 |
|---|---|
| 모두에 '결정일 4회' 게이트 | 재현 블록 A(10/06~11/06)는 결정일이 아니므로 **탐색 채널이 영원히 승인 불가** |
| 모두에 α=0.0125 · Holm(m=2) | 탐색 채널이 사전등록(`보정 없는 0.05`)보다 **8배 엄격**해짐 |

둘 다 사전등록 위반이다. 그래서 트랙을 먼저 확정한다.

## 1. 트랙 정의 — 전부 사전등록 원문에서 온다

### 트랙 C — 확증 (confirmatory)

| 항목 | 값 | 근거 |
|---|---|---|
| 대상 | `차트TOP2` · `수급TOP2` **둘로 닫힘** | §3-5-1 |
| `m` | **2 고정.** 채널이 죽어도 줄이지 않는다 | §3-5-1 |
| 일정 | **결정일 4회** — 2026-10-05 · 2027-01-05 · 2027-04-05 · 2027-07-05 | §3-5-6 문제 2 |
| family α | 결정일당 **0.05 / 4 = 0.0125** | §3-5-6 문제 2 |
| Holm 첫 문턱 | `0.0125 / 2` = **0.00625** | 위 둘의 결과 |
| 검정통계 | **이동블록 부트스트랩**(블록=H, 10,000회, seed 20260913) 단측 p | §3-5-6 문제 1 · §3-5-4 |
| 방향 | `채널 > 대조군` 고정. 음수 t 를 절반으로 깎지 않는다 | §3-5-4 |
| 참고값 | 짝 t · Welch t · 일반 단측 p — **채택 근거가 아니다** | §3-5-6 문제 1 |

### 트랙 E — 탐색 (exploratory)

| 항목 | 값 | 근거 |
|---|---|---|
| 대상 | `리포트TOP2_단기` · `리포트TOP2_중기` (+ §6-7·§6-9 추가 항목) | §3-5-1 · §3-5 계층 2 |
| 일정 | **달력 고정 블록** A `2026-10-06~11-06` · B `11-09~12-09` · C `12-10~2027-01-12` | §3-5-6 문제 3 |
| α | **보정 없는 단측 `p<0.05`** | §3-5-6 문제 3 |
| 표본 | `N≥30` | §3-5-6 문제 3 |
| 검정통계 | 부트스트랩 | §3-5-6 문제 3 |
| 채택 조건 | **1차**(한 블록 통과) **+ 2차**(다음 블록에서 **같은 방향** 재통과). 둘 다여야 채택 | §3-5 계층 2 · §3-5-6 문제 3 |
| 블록 선택 | A 에서 못 넘으면 B 가 1차가 된다. **건너뛰거나 고르지 않는다** | §3-5-6 문제 3 |
| 블록 무효화 | 블록 안에서 `POLICY_SINCE` 가 움직이면 **그 블록 무효** | §3-5-6 문제 4 |

### 트랙 L — 장기 특칙

| 항목 | 값 | 근거 |
|---|---|---|
| 대상 | `리포트TOP2_장기` | §3-3 |
| 일정 | **2026-12월 말 첫 정식 판정** | §3-3 |
| 조기 폐기 | T+20 중간 지표가 랜덤2 T+20 대비 평균 알파 −5%p 이상 열세면 **검토** | §3-3 |

> ChatGPT 지시서는 트랙 L 을 언급하지 않았다. 결정일 4회에도 블록 A/B/C 에도
> 속하지 않으므로, 단일 게이트로 구현하면 **이 채널은 경로가 아예 없어진다.**

### 판정 대상이 아닌 것

`랜덤2` · `랜덤2_배지` · `지수벤치_KOSPI` · `지수벤치_KOSDAQ` · `지수벤치(레거시)` —
대조군이므로 `m` 을 늘리지도, 승인 경로를 타지도 않는다 (§3-1).

## 2. 공통 전제 — 트랙과 무관하게 하나라도 어긋나면 승인 없음

ChatGPT 지시서 P0-5 의 9개 조건을 트랙별 조건과 분리해 재배치한다.
**fail-closed** — 확인할 수 없으면 실패로 본다. `None` 을 통과로 읽지 않는다.

| # | 전제 | 확인 방법 | 현재 상태 |
|---|---|---|---|
| G1 | 입력이 고정돼 있다 | 원장 SHA + 판정기 코드 SHA 를 산출물에 기록 | ✅ 이미 있음(`run_bundle_id`) |
| G2 | **정책 연결이 검증됐다** | 원장 행 ↔ freeze ↔ `policy_id` 대조 | ❌ **미구현**(지시서 P0-6) |
| G3 | 정책 구간이 혼합되지 않았다 | 평가 구간 안에서 `POLICY_SINCE` 불변 | ❌ G2 에 종속 |
| G4 | 날짜별 짝 차이를 만들 수 있다 | `paired_by_date` 가 `k≥2` 이고 분산>0 | ✅ 있음 |
| G5 | 부트스트랩이 정상 수행됐다 | `block_bootstrap_p` 가 `None` 이 아니다 | ⚠️ 함수는 있으나 **판정 경로 미연결**(P0-2) |
| G6 | 표본 문턱을 만족한다 | `N≥30` (§3-1) | ✅ 있음 |

> 🚨 **G2 가 미구현이므로, 이 게이트를 지금 붙이면 `passed` 는 계속 빈다.**
> 그것이 **의도된 결과**다. 달라지는 것은 **"왜 비었는지가 이유와 함께 출력된다"** 는 점이다.
> 지금은 `passed = set()` 이 근거 없는 상수라 이유가 없다.

## 3. 트랙별 게이트

```
gate_confirmatory(today, ctx) -> (allowed, reasons)
gate_exploratory(today, ctx)  -> (allowed, reasons)
gate_long(today, ctx)         -> (allowed, reasons)
```

| | 트랙 C | 트랙 E | 트랙 L |
|---|---|---|---|
| 공통 전제 G1~G6 | 전부 | 전부 | 전부 |
| 시점 | `today ∈ 결정일 4개` | `today ≥ 블록 평가 시점` | `today ≥ 2026-12월 말` |
| α | 0.0125 → Holm(m=2) → **0.00625** | **0.05** 보정 없음 | 미정(§3-3 이 미명시) |
| 추가 조건 | — | **직전 블록 1차 통과 + 같은 방향** | — |
| 실패 시 | `passed` 에 추가하지 않음 + 사유 기록 | 동일 | 동일 |

`allowed=False` 면 그 트랙의 채널은 **어떤 p 가 나와도** `passed` 에 들어가지 않는다.

## 4. 🔴 미정 — 여기서 정하지 않는다. 합의가 필요하다

사전등록에 답이 없는 항목이다. **내가 임의로 정하면 그것이 사후 맞춤이 된다.**

| # | 미정 항목 | 왜 문제인가 | 후보 |
|---|---|---|---|
| **U1** | **블록 표본의 귀속 기준** — 진입일인가 성숙일인가 | 블록 A 를 "10/06~11/06 에 **진입**한 행"으로 볼지 "그 기간에 **성숙**한 행"으로 볼지에 따라 표본이 완전히 달라진다 | (a) 진입일 기준 — 정책 동결(§3-5-6 문제 4)이 진입 기준이라 일관됨 (b) 성숙일 기준 |
| **U2** | **블록 평가 시점** | 블록 A 는 11/06 종료인데, T+5 표본은 그 뒤에야 성숙한다. 평가를 언제 하나 | (a) 블록 종료 + H거래일 후 (b) 다음 블록 시작일 (c) 고정 날짜 |
| **U3** | **트랙 C 의 정책 혼합 규칙** | §3-5-6 문제 4 는 **블록**에 대해서만 썼다. 결정일 평가 구간의 정책 혼합 규칙이 없다 | (a) 결정일 직전 정책 구간만 사용 (b) 전 구간 + 혼합 표시 |
| **U4** | **트랙 L 의 α 와 검정통계** | §3-3 은 날짜만 정하고 문턱을 안 정했다 | (a) 트랙 E 와 동일 (b) 별도 사전등록 |
| **U5** | **트랙 E 의 "같은 방향" 정의** | 부호만인가, 효과 크기 하한도 있나 | (a) 부호만 (b) 1차 효과의 일정 비율 이상 |

> **U1·U2 는 블록 A 가 시작되는 2026-10-06 전에 정해야 한다.** 블록이 돌기 시작한
> 뒤에 정하면 그 시점에 이미 자료를 본 상태가 된다.
> **U3 는 2026-10-05 전에** 정해야 한다.

## 5. 10/5 에 일어나는 두 가지 — 섞으면 안 된다

ChatGPT 지시서는 섞지 않았지만 읽는 사람이 섞기 쉽다.

| | 무엇 | 근거 | 이 게이트와의 관계 |
|---|---|---|---|
| **A** | 🔒 **스위치 강제 조항** — 수급TOP2 폐기 / `SUPPLY_V2_BAND` ON / 분리 중 택1 | §3-2-2 | **무관.** 통계 승인이 아니라 운영 결정이다 |
| **B** | **결정일 1** — 트랙 C 통계 승인 | §3-5-6 | 이 게이트가 적용된다 |

**A 는 B 가 막혀 있어도 실행해야 한다.** G2 미구현으로 B 가 `passed=∅` 여도
A 를 건너뛰면 §3-2-2 의 강제 조항을 어긴다. (단 §3-2-2 는 *"새 근거를 먼저
기록하면 연기 가능"* 이라는 예외를 둔다 — 연기 자체가 아니라 **근거 없는 연기**를 막는다.)

그리고 **2026-10-05 는 개천절 대체휴장**이다. 새 시세를 요구하는 날이 아니라
그날 확보된 마지막 거래일까지의 자료로 하는 것이다(진행계획 v2).

## 6. 출력 스키마 — 참고값과 결정값을 이름부터 가른다

현재는 `nominal_holm_pass` 하나뿐이고 결정 경로가 없다.

| 필드 | 뜻 | 승인 근거? |
|---|---|---|
| `nominal_p` · `nominal_holm_pass` | α=0.05 · 짝 t 기반 **참고값** | ❌ |
| `paired_t` · `welch_t` | 기술 참고 | ❌ |
| `decision_track` | `"C"` / `"E"` / `"L"` / `null`(대조군) | — |
| `decision_gate_open` | 그 트랙의 게이트 통과 여부 | — |
| `decision_gate_reasons` | 막힌 사유 목록 (**비어 있어도 이유가 남는다**) | — |
| `decision_p` | 부트스트랩 단측 p | ✅ 트랙별 α 와 비교 |
| `decision_pass` | 최종 | ✅ |

산출물에 `nominal` 계열은 반드시 **"참고 — 승인 근거 아님"** 문구와 함께 싣는다.

## 7. 구현 순서와 테스트 (합의 후)

| 순서 | 작업 | 지시서 대응 |
|--:|---|---|
| 1 | `block_bootstrap_p` 재표본 정확히 `n` | P0-1 |
| 2 | `holm(pairs, m, alpha)` — α 주입 | P0-3 |
| 3 | 트랙 상수 + 게이트 3종 (fail-closed) | P0-4 |
| 4 | `decision_*` 필드와 부트스트랩 배선 | P0-2 |
| 5 | `passed` 를 게이트 산출로 교체 | P0-5 |

지시서 §8-C 의 9개 테스트에 **트랙 분리 테스트**를 더한다.

```
10. 트랙 E 채널은 결정일이 아니어도 블록 평가 시점이면 게이트가 열린다
11. 트랙 E 에 0.00625 가 적용되지 않는다 (0.05 여야 한다)
12. 트랙 C 채널은 블록 평가 시점이어도 결정일이 아니면 게이트가 닫힌다
13. 트랙 L 은 두 일정 어디에도 안 걸리고 §3-3 날짜를 따른다
14. 대조군은 어떤 트랙에도 배정되지 않는다
15. G2(정책 연결) 미검증이면 **모든 트랙**이 닫힌다
16. 게이트가 닫히면 사유가 비어 있지 않다
```

## 8. 이 설계안이 하지 않는 것

- **문턱·효과크기·블록길이·결정일을 바꾸지 않는다.** 전부 사전등록값 그대로다
- **`passed` 를 열지 않는다.** G2 가 미구현인 한 계속 닫혀 있다
- **스위치를 켜지 않는다.** `ENVELOPE_BAND`·`SUPPLY_V2_BAND` 는 OFF 유지
- **미정 항목(U1~U5)을 정하지 않는다.** 합의 대상으로 남긴다

## 9. 독립성 표시

이 설계안이 다루는 `hyeoks_verdict.py` 는 **Claude 작성분**이고 지적은
**ChatGPT 의 교차검증**이다 — 자기 감사가 아니다.
다만 `docs/전략로드맵.md` 는 **공동 구역**이므로, 이 설계안이 사전등록을
**옮긴 것**인지 **바꾼 것**인지는 제3자 확인이 바람직하다.
