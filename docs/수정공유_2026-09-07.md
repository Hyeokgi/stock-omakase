```python
# hyeoks_tajeom.py
OVERSOLD_TAG = "📉 과매도 · 역배팅"
RISK_WORDS = ("하락 전환", "3파 익절", "고점 리스크", "반등 미확인", "하락장")

def is_downtrend_risk(tajeom_raw):
    raw = tajeom_raw or ""
    if any(k in raw for k in RISK_WORDS):
        return True
    return "📉" in raw.replace(OVERSOLD_TAG, "")   # 태그를 뺀 나머지에 📉 가 또 있으면 위험
```

- 프롬프트 규칙 4에 예외 조항을 넣되 **2번(중기) 자리에만** 적용했습니다.
