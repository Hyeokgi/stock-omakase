**끊긴 곳 · 위험**
1. **pool_150 의 입력 실행이 기록되지 않는다.** 리포트(15:01~15:02)는 15:05 첫 적재 실행보다 먼저 돌아 직전 실행(15시 무렵)의 시트를 읽는다. 그 실행의 영수증 · Feature Store 가 없다. '같은 후보군에서 규칙 vs AI' 비교(선정 추가 효과, 종합 5번)는 종목으로는 이어지지만 점수 · 가격은 15:05 FS 와 몇 분 다르다 — 비교 설계에서 이 차이를 명시하거나, 동결 묶음 자체의 점수를 기준으로 삼는다.
2. **0행과 결측을 구분해야 한다.** 순위 풀 0행(신호 없음)과 색인에 없는 날(보관 실패)은 다르다. 색인 상태와 영수증 행 수를 함께 본다.
3. 장중 분봉 프로파일 · 실적 · 컨센서스는 이름만 보면 15:05 변수 같지만 그날 밤 자료다(1절 표).
4. 2026-10-25 이전 공개 영수증의 거래 ID 에 종목코드가 남아 있다(이력). 새 영수증은 HMAC.
