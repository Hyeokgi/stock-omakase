## 정의 (고정)

| 항목 | 값 |
|---|---|
| 조회 | 한투 Open API `news-title`(tr `FHKST01011800`), 조건 없이 최근 40건. 기존 `KIS_APP_KEY/SECRET`, 실행당 토큰 1회 발급(구글 시트 토큰 칸은 읽지도 쓰지도 않는다) |
| 시각 | 거래일 09:10 ~ 15:08 KST, **10분 간격**. 깃허브 예약 09:10·11:10·13:10(뒤 둘 백업, 늦게 시작한 실행은 아무것도 안 함) |
| 넘침(사용자 지시대로) | 한 조회가 40건 꽉 찼는데 **그중 이미 본 건이 하나도 없으면** 사이 뉴스를 놓쳤을 수 있다 → `넘침 의심` 으로 세고 **최신 40건만 받은 그대로** 둔다(뒤로 넘겨 받지 않는다). 놓쳤을 수 있는 구간 = (이전 조회에서 본 가장 늦은 게시 시각, 이번 조회의 가장 이른 게시 시각) |
| 알림 | 넘침 의심이 있으면 그날 `[연구]` 텔레그램 보고에 횟수를 쓴다 |
| 중복 | 일련번호 `cntt_usiq_srno` 기준(없으면 게시 날짜·시각·제공처·제목 지문) |

| 저장 | 원본(제목·관련 종목 포함)은 드라이브 비공개. 공개 `data/research_runs/kis_news_runs.csv` 는 건수만(조회·실패·뉴스 수·종목코드 붙은 수·15:05까지·넘침 의심·상태) |
