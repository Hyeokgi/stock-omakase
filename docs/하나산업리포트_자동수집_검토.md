# 하나증권 산업리포트 자동수집 검토

2026-09-13 / 구현·활성화 전 범위 확인. 이번 요청의 "가능하다면 고려"에 대한 조사 결과.

## 확인한 사실

하나증권 공식 산업분석 목록에 제목·게시 날짜/시각·PDF 링크가 노출된다.
[공식 산업분석 목록](https://www.hanaw.com/main/research/research/list.cmd?pid=3&cid=1).
따라서 네이버에서 매주 사람이 다운로드하는 단계를 대체할 후보 경로가 있다.
다만 실제 HTML 파서·다운로드·Drive 업로드를 종단 간 시험하거나 자동 작업을 켠 것은 아니다.

현재 사용자가 받는 특정 주간 시리즈/전체 산업분석 여부와 실제 저장 폴더/소비 경로는
확인 중이다. 이 정보 없이 모든 PDF를 기존 AI 입력 폴더에 넣으면 비용·후보군·정책이
의도하지 않게 바뀐다. 네이버 등재본과 원문이 같은지도 초기 대조가 필요하다.

## 권장 설계

1. 공식 목록을 저빈도로 확인. 대상 시리즈/기간은 설정으로 제한한다.
2. 보고서 ID·첨부 ID·원문 URL·제목·게시 시각·최초 발견 시각을 기록한다.
3. 새 대상 PDF만 TLS/HTTP 상태·파일 서명·크기 한도를 확인하여 비공개 저장한다.
   URL/보고서 ID와 내용 SHA256으로 중복 방지. 같은 ID의 정정본은 새 버전으로 기록한다.
4. 목록 페이지 누락·파싱 실패·403/429는 빈 목록 성공으로 처리하지 않는다.
   마지막 정상 수집 시각, 페이지 범위, 성공/실패 건수, 재시도 상태를 표시한다.
5. 최초에는 전용 수신함에만 저장하고 수동본과 대조한다. 기존 분석 입력 연결은 그 후에 한다.
   AI 재분석 여부는 파일 버전 기준으로 관리하여 동일 보고서의 반복 과금을 막는다.
6. 발행일/게시 시각/최초 발견 시각/시스템 투입 시각을 구분한다. 과거 PDF를 오늘 받은 뒤
   과거 시점에 이미 읽은 것으로 백테스트에 사용하지 않는다.
7. 본문은 신뢰할 수 없는 입력 데이터다. 문서의 지시문으로 시스템 규칙/인증정보 처리를 바꾸지 않는다.

PDF 본문을 공개 GitHub 저장소에 커밋하거나 재배포하지 않는다. 이용조건·수집 허용 범위를
확인하고 접근 제한을 우회하지 않는다. 브라우저 화면 반복 조작보다 원문 링크 수집이 유지보수에 유리하다.
이 자동수집은 투자 판단 자동화나 새 전략 채택을 뜻하지 않는다.

다음 연결에 필요한 정보: 현재 받는 보고서 링크/제목 예시 1개, 저장 위치, 전체 하나 산업분석인지
특정 주간 시리즈인지. 월별 경제일정 PDF용 `hyeoks_calendar_ingest.py`는 용도가 달라 그대로 재사용하지 않는다.
