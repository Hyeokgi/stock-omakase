### 🔎 병목이 갈렸다 — 이격이 아니라 거래대금 쪽이다

```

   이격 3 → +거래대금(100억) 0 → +상한가·등락률 0 → 과매도·역배팅 0건
```

**이격 조건은 0이 아니었다. 3종목이 통과했다.**
옛 코드였다면 이 상황에서 `"-20% 이탈 종목 자체가 0"` 을 찍었을 것이다.

**두 계측이 서로를 검증했다** — 스캐너 715종목 중 태그 0건, 분석기 원시 716종목 중

⚠️ **하루 관측이고 그날은 `warning_market=Y`(경계장)라 거래대금 문턱이 100억**

## 2. 시간외 표시가 **실제로 시트에 닿았다**

ChatGPT 가 반복해 지적한 *"테스트 성공과 시트 배포 성공은 구분한다"* 를 확인할
수단이 없어서 `hyeoks_sheet_probe.py`(읽기 전용)를 만들었고, 16:20 KST 에 돌렸다.

### 제목 — 일치

```
DB_스캐너 Q1:R1      ['시간외 관측(시장·기준·시각 표시)', 'NXT 관측(확인된 시장만)']
주가데이터_보조 AA1:AC1 [… 같은 둘 …, '장구분']
```

`119f9aa` 가 코드에서 끝나지 않고 **시트까지 반영됐다.**

### 값 — 새 표기법대로 써지고 있다

```
전일종가 대비 -2.13% (137,800원) / 정규장종가 대비 미확인
  [시장 미확인 / 2026-09-15 16:13:45 KST]
미확인(당일 시간외 시세 없음)          ← 시세 없는 종목
장구분: 시간외(시장 미확인)
```

| ChatGPT 보고서의 약속 | 실제 |
|---|---|
| generic 은 시장 미확인, NXT 추정 금지 | ✅ `[시장 미확인]` · **NXT 열 전부 빈칸** |
| 제공처 등락률은 산술 일치할 때만 | ✅ `전일종가 대비 -2.13% (137,800원)` — 기준 명시 |
| 오늘 정규장 종가 인증 소스 없음 | ✅ `정규장종가 대비 미확인` |
| 시세 시각 기록 | ✅ `2026-09-15 16:13:45 KST` |

옛 방식의 `0.00%` 나 NXT 단정이 **하나도 없다.** 시세가 없으면 조용히 0을 넣지 않는다.

> ⚠️ **값의 정확성을 인증한 것이 아니다.** "그 칸에 무엇이 있나" 까지다.
> ChatGPT 보고서도 *"거래소별 가격·오늘 정규장 종가를 확인한 완전한 계산기까지
> 완성한 것은 아니다"* 라고 스스로 한계를 그었고, 그 한계가 지금 시트에
> `정규장종가 대비 미확인` 으로 정직하게 표시되고 있다.

⚠️ **장중(09:00~15:40)에는 값이 비어 있는 것이 정상이다** — `omakase.py:2685` 가
그 칸을 비운다. 그래서 15:30 확인은 제목까지만 가능했고, 값은 16:20 에 봤다.
probe 가 그 구분을 출력에 넣는다. 자기검증에 두 경우를 다 넣었다.

### G — 🟠 **원인 진단이 의심 대상이 됐다**

> *"리포트중기 채널이 굶고 있음 — 8/14 이후 신규 적재 0. **원인은 −20% 엔벨로프 문턱**"*

## 4. 명칭 변경 — `타점 인구조사` → `타점 전수조사`

사용자가 *"인구조사가 사람에 대한 조사인지 그냥 명칭인지 모르겠다"* 고 물었고,
**그 질문 자체가 이름이 나쁘다는 증거다.** 2026-08-31(`c6319c2`)에 내가 census 를
한국어로 옮기면서 뜻은 맞지만 어감을 놓쳤다 — '인구주택총조사' 가 먼저 떠오른다.

세는 것은 사람이 아니라 **그 회차에 스캔한 전 종목**(9/15 기준 715개)이다.
의도한 뜻은 census = **전수조사**, 즉 표본을 뽑지 않고 모집단 전체를 센다는 것이다.

| | |
|---|---|
| 바꾼 것 | `omakase.py` · `scanner_census.py` · `main.yml` · `tests` · 정책변경 체크리스트 |
| 바꾸지 않은 것 | **경로·열 이름**(`data/scanner_census/`, `CENSUS_PATH`) — 영어 census 는 정확하고, 커밋된 관측 파일의 연속성을 끊지 않는다 |
| 바꾸지 않은 것 | **날짜가 박힌 과거 기록** — 9/14 수정보고, 외부검증 의뢰서, 로드맵 §3-2-0 의 9/1 문장. 당시 그 이름이었다는 것이 기록이다(운영 대전제 §5) |

옛 로그를 찾을 수 있게 `omakase.py` 에 breadcrumb 을 남겼다.

### 덤 — 권위 문서에서 같은 오독을 찾았다

전략로드맵 §3-2-0 의 `엔벨로프 통과 0/701` 도 **복합 조건** 통과 수다.
`-20% 이탈 종목이 0` 으로 읽히면 안 된다. 9/14 에 스캐너에서 고친 것과 같은
오독이 로드맵에 남아 있었다. 당시 문장은 그대로 두고 아래에 보완만 덧붙였다.
