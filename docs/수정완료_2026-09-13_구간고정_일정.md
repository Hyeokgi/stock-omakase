## 1. 종베: 설명과 실제 코드의 불일치 수정

이전 분석기는 누적 전체 자료로 매번 σ와 N을 다시 정하고, 최종 검정에도 파일럿을 포함했다.
또한 날짜별 새 파일을 만들 수 있어 판정 1회 잠금이 아니었다.

- `closing_study.py` 추가: 최초 유효 20일로만 σ/N 결정. 길이를 영속 상태로 보존.
- 본 구간은 그 이후 최초 N개 유효 날짜. 파일럿과 N 이후 자료는 최종 통계에서 제외.
- 파일럿, 누적 본 구간 접두부, 완료 본 구간의 날짜/통계 지문을 고정한다.
  뒤늦은 백필·가격/탈락 변경으로 기존 구간이 달라지면 중단한다. 자동 재판정 금지.
- 최종 보고서는 상태에 보존하며 후속 실행에서 같은 결과만 재표시한다.
  파일 이름도 `docs/종베판정_closing-window-v2.md`로 고정. `--force`도 판정을 덮어쓰지 못한다.
- 기본 상태 파일 `data/closing_bet/study_v2.json`은 첫 유효 파일럿 완료 시 생성된다.
  상태는 합성 시험의 JSON 왕복 저장 후에도 유지됨을 확인했다. 실제 파일럿은 아직 미완이다.
- `--stdout-only`는 미저장 미리보기임을 표시한다. 상태 파일을 삭제/바꿔가며 유리한 결과를
  택하지 않는다. 정책 개정 시 기존 상태/입력/결과를 보존하고 별도 연구 버전을 검토한다.
- stage 0도 익일 시가·분위별 유효 수를 검사한다. 단, 수익률은 계산하지 않는다.
  시가 부재인데 날짜 파일이 있다는 이유만으로 성숙일로 세던 문제를 수정했다.
- 비유한 숫자 NaN/Inf는 유효 가격으로 사용하지 않는다.
- `capturedAt`은 수집 시작 시각이다. 실제 시세 시각이나 백업 cron 실행의 증거로 표현하지 않는다.

유지: Q5 주 비교, 15:05 진입/익일 시가 전량 청산, 비용 가정, 효과 목표,
HAC 지연, 표본 수 규칙, 독립 재현 전 채택 금지. `passed`/`hit` 잠금은 해제하지 않았다.
이 수정은 HAC/부트스트랩의 유한표본 오차율이나 검정력을 새로 인증한 것은 아니다.
기업행사 의심 필터와 익일 가격 부재에 따른 제외 편의, 실제 체결 가능성은 잔여 검증 과제다.

  지수 봉이 없거나 HTTP/파싱이 실패하면 정상 휴장으로 숨기지 않고 오류를 전달한다.

## 3. 실패 전파와 TLS

- `market_snapshot.yml`에서 읽히지 않는 exit_code 출력/정상 종료를 제거했다.
  수집 실패는 작업 실패로 전파되며 성공한 수집물만 다음 커밋 단계로 간다.
- `closing_bet.yml`은 상태 파일도 커밋하고 동일 연구 동시 실행을 직렬화한다.
  push 경쟁 시 fetch/rebase 후 재시도하며 마지막 실패는 숨기지 않는다.
- `hyeoks_analyst.py`의 인증서 검증 해제 10곳 제거, 인증서 경고 억제 제거,
  차트 이미지 요청의 누락된 timeout 추가. 스냅샷 개장 확인 요청 1곳도 검증 복원/HTTP 상태 확인.
- 로컬 기본 인증서 검증으로 m.stock.naver.com, fchart.stock.naver.com,
  ssl.pstatic.net의 공개 URL을 조회해 모두 HTTP 200 확인(본문 일부만 확인).
  requests 기반 장중 전체 경로/인증 KIS API 실측을 대신하지 않는다.
- 다른 파일의 `verify=False`는 남아 있다. 이번 변경을 저장소 전체 TLS 정리 완료라고 쓰지 않는다.
