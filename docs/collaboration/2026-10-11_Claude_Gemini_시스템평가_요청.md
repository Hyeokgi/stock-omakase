## 4. 보고 형식

1. **기준**: 실제로 읽은 커밋 SHA, 읽은 파일 범위, 실행한 것(있다면 명령과 환경)과 실행하지 않은 것.
2. **발견 (심각도 순)** — 각 항목마다:
   - 분류: P1(데이터 손실·판정 오류·공개 유출) / P2(잘못된 표시·복구 공백) / P3(개선)
   - 근거: `파일:줄` 또는 커밋, 재현 입력(가짜 응답·가짜 시트로 재현했으면 그 방법)
   - 영향과 고치는 방법. 고칠 파일이 **지문 대상**인지(바꾸면 3거래일 연속 판정이 0 부터 다시 시작) 표시
   - 확인한 사실과 추정을 구분해 쓴다
3. **잘 된 점** — 짧게.
4. **확인하지 못한 것** — 접근할 수 없었던 것(시트·드라이브·실제 실행 로그 등)과 그 이유.
