## 3. 제안만 남긴 것

1. **기본 /api의 상단 새로고침 경로 통일.** 기본 주소에서도 버튼이 실제 요청하도록 하는 변경은 데이터 요청 동작 범위이므로 별도 수정으로 검토한다. 당겨서 새로고침·3분 갱신은 기존대로다.
2. **자료 시각 계약 보강.** 현재 녹색의 ‘실시간’은 응답 나이 기준이며 시세 원천 수집 시각을 보증하지 않는다. lastLive 저장 시각과 실제 자료 나이도 다를 수 있다. 원천 시각과 날짜를 정확히 표시하려면 저장·응답 계약 검토가 필요하다. 이번에는 PR #15의 문구·판정·저장 동작을 그대로 두었다.
3. **첫 화면 정보 밀도.** 터치 영역 확대와 상태 줄 분리로 카드 시작 위치가 내려간다. STAGE를 축약하거나 요약 스트립 위치를 바꾸는 작업은 휴대폰 실측 후 정보 우선순위를 결정하는 것이 좋다. 이번에는 신호나 경고 내용을 숨기지 않았다.
4. **모달·리스트 접근성 후속.** 설정·매뉴얼의 초점 가두기, Escape 닫기, 닫은 뒤 초점 복원, 매뉴얼 iframe 내부와의 이동을 함께 검증할 필요가 있다. 뉴스·리포트·테마 행과 복기 태그·일정 펼침의 모든 클릭 영역을 키보드 조작으로 전환한 것은 아니다. 관심종목 드래그의 키보드 대안과 실행취소 토스트도 후속 범위다.
5. **내장 매뉴얼 별도 검토.** 좁은 화면의 다열 표와 도표, 현재 운영 지침과 과거 전략 설명의 차이는 별도 점검이 필요하다. 투자·전략 의미를 바꾸지 말라는 지시에 따라 매뉴얼 본문은 그대로 보존했다.
6. **모션 감소·제스처 충돌.** 탭 전환은 transitionend에 의존하므로 애니메이션 제거를 단순 CSS로 적용하면 전환 종료가 어긋날 수 있다. 요약 가로 스크롤과 좌우 탭 스와이프도 실기기에서 함께 확인한 뒤 수정한다.

## 5. 직접 확인하지 못한 것과 다음 행동

- 실제 320·360·390·430px 화면, iOS Safari·Android Chrome, 다크·라이트 화면 캡처, 200% 확대, 터치와 드래그, 가상 키보드·안전 영역, TalkBack·VoiceOver 검증은 못 했다. CSS 목표 치수는 실제 화면 측정값이 아니다.
- 로컬 헤드리스 Chrome은 `GPU process exited unexpectedly: exit_code=-1073741790`, `GPU process isn't usable`로 종료됐다. 브라우저 도구의 `http://127.0.0.1:9338` 접근도 자동 승인 검토에서 거부됐다. 도구는 해당 주소의 사용자 접근 승인이 허용되지 않았다고 보고했다. 우회하지 않았고 임시 미리보기 서버를 종료했다.
- 실제 GAS·Worker 운영 응답, 느린 네트워크·오프라인에서의 첫 접속, 외부 차트·로고 로딩은 이번에 직접 호출·확인하지 않았다.
- `git fetch origin main`은 작업 트리 밖 FETCH_HEAD 권한 문제로 실패했고 `ls-remote`는 schannel 인증 오류였다. GitHub 연결 도구로 원격 main이 기준 HEAD와 같음을 확인하고 허브·열림 기록 6개를 읽었다. 허브 blob은 원격과 로컬 모두 `63d6765b38bbbf0375737f42e5321d24dc64a424`였다.
- 다음 행동은 사용자가 허용한 브라우저 환경에서 위 화면 크기별 배치·접근성·제스처와 첫 접속을 검증하고, 결과에 따라 이 로컬 변경을 검토하는 것이다. 배포 완료나 타인의 승인으로 기록하지 않는다.
