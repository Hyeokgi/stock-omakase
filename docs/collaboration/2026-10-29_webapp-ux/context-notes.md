# 웹앱 개선 맥락

## 착수

- 지시 파일은 `Get-Content -Encoding UTF8`로 읽었다. 후속 명시 지시인 커밋·푸시 금지가 기존 자동 커밋 지침보다 우선한다.
- 작업 폴더 밖 결과 파일은 쓰기 허용 범위가 아니므로 지시된 저장소 내부 대체 경로를 사용한다.
- git fetch는 FETCH_HEAD 권한 오류, ls-remote는 schannel SEC_E_NO_CREDENTIALS로 실패했다. GitHub 연결 도구로 main 커밋 `8a7addf00659a39feaee16ead82dde8cfa327b01`과 허브·열림 기록 6개를 읽었다. 로컬 HEAD와 원격 main이 같다.
- `stability_gate.py`의 FINGERPRINT_FILES에 화면 파일은 없다. 지문 파일·Worker·설정·Python·data는 수정하지 않는다.
- 루트 checklist.md/context-notes.md는 이전 작업 기록이므로 보존하고 이번 작업 자료를 별도 폴더에 둔다.
- node v24.18.0 사용 가능. rg와 Playwright/Puppeteer 모듈은 없다. Python은 실행하지 않는다.
- CSS와 UI 이벤트만 작은 단위로 수정한다. 보호 함수, 데이터 필드 접근, 요청 URL·매개변수는 변경하지 않는다.

## 구현과 검증

- 기존 3,154줄 전체를 읽었다. liveDot은 이미 상태 문구를 제공하므로 문구 생성은 보존하고 줄 배치·크기·상태 알림만 바꿨다. 화면 현재 시각의 ‘기준’ 표현은 ‘화면’으로 바꿨다.
- 터치 영역 확대 때문에 좁은 카드의 이름·가격에 줄바꿈을 허용했다. 상세 내용은 최대 높이 제한을 없애 긴 내용 잘림을 막았다. 펼침 애니메이션의 연속 보간은 줄어들 수 있다.
- 기본 /api에서 상단 새로고침이 요청하지 않는 기존 동작을 발견했으나 요청 동작 보존 지시로 변경하지 않았다. 매뉴얼 투자 문구·원천 자료 시각·모달 전체 접근성은 후속 제안으로 남겼다.
- 기존 Worker 시험 8개 시나리오, 인라인 JS 2개 구문, 보호 함수·초기화·매뉴얼·요청 문자열 대조와 모의 DOM 조작 검증을 통과했다. 상세 내용은 결과 보고서에 기록했다.
- 브라우저 검증에 computer-use 스킬을 읽었다. Chrome 헤드리스 GPU 프로세스가 권한 오류로 종료됐고, 연결된 브라우저의 localhost 미리보기 접근도 자동 승인 검토가 거부했다. 우회하지 않았다. 미리보기 서버는 종료했다.
- 실제 화면·터치·보조기기 검증을 수행했다고 주장하지 않는다. 모의 DOM 검증은 레이아웃·브라우저 기본 키보드 동작 검증을 대신하지 않는다.
- 결과 파일은 사용자 지시의 대체 경로에 작성했다. 기존 과거 기록을 보존하고 허브 §4에는 새 행 하나만 추가했다. 커밋·푸시·배포하지 않았다.
