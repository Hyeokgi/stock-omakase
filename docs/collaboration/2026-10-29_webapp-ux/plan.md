# 웹앱 모바일 사용성 개선 계획

기준 커밋은 `8a7addf00659a39feaee16ead82dde8cfa327b01`, 작업 브랜치는 `design/webapp-ux`다.

1. 화면 전체와 운영 제약을 읽고 문제를 줄 번호로 기록한다. 검증은 원격 main 대조와 지문 대상 목록 확인으로 한다.
2. 작은 터치 영역, 좁은 화면 넘침, 낮은 대비, 검색 빈 상태와 기본 접근성을 개선한다. 기존 데이터 계약과 첫 접속 저장본 동작은 유지한다.
3. 인라인 스크립트 구문, 기존 Worker 시험, 가능한 브라우저 검증을 수행한다. 보호 함수와 요청 문자열은 기준 커밋과 대조한다.
4. 결과 보고서와 공동작업 허브를 기록한다. 사용자 지시에 따라 커밋·푸시·배포는 하지 않는다.

가정은 모바일 우선의 작은 개선이며 탭 순서·신호·점수·투자 문구를 재설계하지 않는다는 것이다. 결과 보고서는 허용된 대체 경로인 `docs/collaboration/2026-10-29_Codex_웹앱_디자인개선.md`에 쓴다.
