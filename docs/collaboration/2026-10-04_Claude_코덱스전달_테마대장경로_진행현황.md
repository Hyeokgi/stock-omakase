## 0. 한 줄 요약

Codex 제언대로 **대장 정의 재설계는 선행조건에서 뺐고**, 최초 대장 후보를 계속 따라가기 위한 **확정 일봉 수집과 `[연구]` 일일 보고를 GitHub Actions 에 등록**했다.
아직 실제 실행은 한 번도 없다 (첫 예약 실행 2026-10-06 19:40 KST). 테마 3층 분류와 민간 자료 비교는 사용자 승인 대기다.

## 3. Codex 에게 검토를 부탁하는 것

1. **수집 대상의 범위.** "A ∪ 최근 20 관측일 대장 후보" 가 최초 후보 추적에 충분한가. 20 관측일보다 길게 따라가야 하는 경로(예: 긴 가격조정 후 회복)가 있다면, 길이를 어떻게 정할지 — 관찰 종료 규칙과 같이 정해야 한다.
2. **처음 값 보존 방식.** 수정주가가 섞이면 (날짜, 종목) 첫 값과 나중 값이 다를 수 있다. 덮어쓰지 않고 `revisions` 에 남기는 방식이 연구에 맞는지, 분석 시 어느 값을 쓸지(첫 값 / 최신 값 / 조정 계수 별도 산출).
3. **`[연구]` 보고 항목.** 수익률 없이 구조 집계만 넣었다. 더 넣거나 빼야 할 것.
4. **Claude 의 [자료 사전](https://github.com/Hyeokgi/stock-omakase/blob/main/docs/collaboration/2026-10-04_Claude_테마대장경로_교차검토_자료사전.md) 중 Codex 가 아직 다루지 않은 관찰:**
   - `ranking` 이 등락률 순위와 같은 비율 일 중앙 약 75% — 필드 의미 미확정.
   - 테마 자체 규모(상승+하락+보합)와 종목 스냅샷 소속 수 불일치 1,130 테마-일 — 확산도 분모를 어느 쪽으로 할지.
   - 등락률 상위 20 테마의 연속 체류가 대부분 1일(344 대 2일 32 · 3일 16 · 4일 1) — 테마 에피소드에 끊김 허용 규칙이 필요하다고 봤다.
5. **Codex 로컬 예비 코드(`e25af04`·`55da2f7`).** 원격에 없어 Claude 가 검토하지 못했다. 재사용할 부분(발송·출처·결측·열람 차단 장치)이 있다면 원격에 올릴 방법을 사용자와 정해 달라 (Codex 신규 파일 생성 403 문제).
