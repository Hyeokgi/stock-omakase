# 장전시황 시간외·프로그램 표시 수정

- 기준 커밋. [`6b6b832`](https://github.com/Hyeokgi/stock-omakase/commit/6b6b8328e305ad010496066cdd6b13dae6accde3). 이 수정 커밋은 원격 쓰기 권한 부재로 아직 공개 저장소에 반영되지 않았다.
- 담당자. Codex. 사용자 요청에 따른 진단·표시 수정.
- 범위. `hyeoks_morning.py`의 시트 입력 해석·Gemini 지침·발송 직전 오표기 차단을 수정했다. `omakase.py`의 원천 수집·V2 점수, 시간외 원장, 자동주문은 건드리지 않았다.
- 실제 검증 결과. 2026-10-09 조회한 `주가데이터_보조` 745행 중 프로그램 열은 700행이 0이 아니고 45행이 `0.0억`이었다. 시간외 열은 279행에 관측 시각이 있고 466행은 미확인, 확인된 NXT 열은 전부 빈칸이었다. 즉 원자료가 모두 0·특이사항 없음인 것은 아니다. 관련 단위시험 19건 통과. 전체 980건 중 2건은 Windows의 쓰기 불가 경로 가정, 1건은 `bash` 부재로 실패했다(전체 실행은 최종 문구 가드 추가 전). 지문 대상 파일은 변경하지 않았다.
- 확인한 문제. 모닝 브리핑은 거래소가 확인되지 않은 시간외 AA열을 KRX라고 부르고, NXT 결측이어도 두 시장을 비교해 시가 갭을 예측하도록 요구했다. 스캐너는 프로그램 조회 실패를 `0.0억`과 구분하지 못하고, 새벽 재스캔이 전날 시간외 값을 미확인으로 바꿀 수 있다.
- 미검증 사항. 수정된 브리핑의 실제 텔레그램 출력과 Gemini의 지침 준수는 아직 생산에서 검증하지 못했다. 시간외 원천의 거래소·당일 정규장 종가 대비 수익률, 프로그램 0의 진위도 확인되지 않았다.
- 다음 행동. 다음 거래일 장전 메시지의 실제 표기와 시트 입력을 대조한다. 스캐너 지문 대상 변경은 안정화 판정 재시작 영향에 대해 사용자 승인을 받은 뒤 별도 변경·시험으로 처리한다.
- 사용자 승인 필요 사항. `omakase.py`의 프로그램 결측과 새벽 시간외 보존까지 수정할지 결정이 필요하다. 수정하면 안정화 지문이 바뀌어 3거래일 연속 판정이 0부터 다시 시작된다.
- 타인의 검토·승인 상태. 없음.
