# 웹앱 금요일 관측 탭 — C단계 (2026-10-30, PC Claude)

## 사용자 요구 (2026-10-30)
"금요일 1~2위 종베와 시간외(20:00) 하락률을 계속 추적하는 연구 전략 페이지" → "C단계 금요일 페이지 진행해".

## 지킨 것
관측 두 개(금요일 1~2위 반씩 종가 매수 · 금요일 밤 하락 20:00 매수, PC 허브 등록)는 **판정일(2027-04-26 중간 · 2027-10-25 최종) 전 결과를 보지 않기로 사전 등록**됐다. 그래서 월요일 시가 결과는 기록하지도 보여 주지도 않는다. 화면에는 후보 · 금요일 밤 하락률 · 건수 · 등록 전 과거 탐색 결과만 둔다.
