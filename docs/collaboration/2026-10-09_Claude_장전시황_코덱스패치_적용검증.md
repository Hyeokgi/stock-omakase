## 2. 검토 — 동작 변경은 장전 표기뿐

- 시간외 칸: 원천 문자열의 날짜가 **직전 예정 거래일**이면 그대로 보이고, 아니면 `미확인`. 시장은 항상
  `시장 미확인` 으로 표기한다(KRX 라고 단정하지 않음). 형식 출처를 확인했다.
  - 정기 운영: `omakase.py` → `after_market_quotes.scanner_after_quote` 의 `[시장 미확인 / YYYY-MM-DD HH:MM:SS KST]`.
  - 수동 전용: `hyeoks_nightly.py`(nightly_batch, `workflow_dispatch` 만)의 `[조회 YYYY-MM-DDTHH:MM:SS+09:00; 체결시각 미확인]`.
- 프로그램 `0.0억`: `omakase.py:1583` 의 초기값과 같은 문자열이라 실제 0 과 조회 실패를 구분할 수 없다 → `미확인`.
  0 이 아닌 값은 그대로.
- 직전 거래일: 등록 휴장 달력을 쓴다(10/12 → 10/8, 10/6 → 10/2). 달력 범위 밖이면 `ValueError` → 모두 `미확인`(안전 쪽).
- Gemini 지침에서 "KRX·NXT 대조로 시가 갭 예측" 강제를 뺐고, 발송 직전 정확한 두 문구를 한 번 더 바꾼다.
- `omakase.py`·선정 문턱·원천 수집·자동주문은 바뀌지 않았다.
