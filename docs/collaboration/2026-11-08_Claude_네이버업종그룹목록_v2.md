- `hyeoks_market_snapshot.py` — 업종 · 그룹 목록을 테마와 같은 rankings v2(`industries` · `groups`, 커서)로 받는다. 11/08 실측으로 v2 의 code · name 이 11/05 파일의 no · name 과 업종 79 · 그룹 61 **모두 같다**.
