## 1. 연구 일봉 — 가격 원자료 비공개, 상태 없는 수집

**보관 위치.** 동결 번들이 쓰는 구글 드라이브 **쓰기 전용** 창구(`hyeoks_run_freeze.upload`, GAS 웹앱)를 그대로 쓴다.
비공개 저장소+토큰 방식은 이 세션에서 저장소 비밀값(secrets)을 등록할 수 없어(프록시 403) 사용자 작업이 필요했다 — 이번에는 추가 설정이 필요 없는 길을 택했다.

**쓰기 전용이라 러너가 지난 자료를 읽을 수 없다 → 상태 없는 수집으로 바꿨다.** 매 실행 대상 전 종목의 최근 300봉을 새로 받아 하루치 파일로 올린다.

| 파일 (드라이브, 비공개) | 내용 |
|---|---|
| `research_bars_<대상일>_<실행ID>[_partNofM].csv.gz` | date·code·OHLCV(원천 숫자 그대로)·종목별 수신 시각. gz 3MB 를 넘으면 종목 단위로 나눈다 |
| `research_bars_<대상일>_<실행ID>_status.json.gz` | 실행 메타 + 종목별 상태(봉 수·첫/끝 날짜·검사 탈락 사유·무거래 봉·분류·오류) |

| 공개 (`data/research_runs/`) | 내용 |
|---|---|
| `last_run.json`, `runs.csv` | 건수·상태·비공개 파일 이름·드라이브 id·크기. **가격·종목별 상태 없음** (시험이 확인) |
| `resume.json` | 시간 예산으로 멈춘 위치(정수 하나) |

`.gitignore` 에 `data/daily_bars/` 추가. 이 경로는 한 번도 커밋되지 않았다(첫 실행 전).

**Codex 후속 A (시간 제한 반복 시 뒤 종목 굶음).** 순서 = 우선 구간(지수 + 그날 A ∪ 최근 20 관측일 대장 후보, 항상 먼저) → 나머지(저장된 모든 스냅샷 날의 A, `resume.json` 위치부터 돌림).
예산으로 멈추면 다음 실행이 멈춘 곳부터 잇는다. 시험: 첫 종목까지만 처리할 예산을 두 번 줘도 요청 이력이 `[000001, 000002]`.

**Codex 후속 B (일부 봉 탈락을 완료로 인정).** '초기 수집 완료' 상태 자체를 없앴다 — 매일 같은 300봉 창을 다시 받는다.
종목별 실행마다 `완전 / 짧은응답 / 검사탈락 / 대상일없음` 으로 나눠 남긴다. 짧은 응답은 '상장 이력이 짧음' 으로 인증하지 않는다.
재시도는 하루 한 번 요청이라 무한 반복이 아니다. 같은 종목이 며칠 계속 탈락하는지는 비공개 상태 파일로 나중에 본다.

**덤으로 생긴 것.** 매일 300봉을 다시 받으므로 오래된 봉의 수정주가 변경도 매일 탐지할 수 있다(Codex ②가 지적한 '최근 5봉 재수집으로는 못 잡음' 해소). 비교는 비공개 파일끼리 한다.

**비용.** 하루 약 2~4MB(gz)·파일 2~3개가 드라이브에 쌓인다(연 약 1GB 미만 예상, 실측 전). 동결 번들·PDF 와 같은 폴더에 섞인다 — 폴더 분리는 GAS 스크립트 수정이 필요하다(사용자 작업).

## 2. stockinfo7 병행 수집 (`hyeoks_theme_source_collect.py`, `theme_source_collect.yml`)

- 평일 12:30 KST 예약 → 16:35 KST 까지 10분 간격(약 24회). 깃허브 예약 지연 시 관측만 줄고 끝 시각은 같다. 휴장일 건너뜀. 간격 하한 300초.
- 관측마다 공개 메타 한 줄(`data/research_runs/stockinfo7_obs.csv`): 요청 시작·수신 완료(KST)·HTTP·분류·기준 시각 문구·카드/종목 행 수·내용 지문·비공개 파일 이름. **테마·종목 이름 없음.**
- 첫관측·갱신 화면만 파싱 결과 + 원본 HTML 을 모아 드라이브에 올린다(`research_stockinfo7_<날짜>_<시각>_<실행ID>.json.gz`) — 15:10 이후 첫 관측 때 한 번, 끝날 때 한 번, 중단돼도 `finally` 로.
- 로그에도 이름을 찍지 않는다. 진단 도구(`theme_source_probe.yml`)는 수동 진단용으로 남긴다.
- `[연구]` 일일 보고에 한 줄: 관측 수·갱신·오류·**15시본 첫 수신 시각과 15:05 전/후**.

**아직 모르는 것.** 15시본이 15:05 전에 뜨는지, 하루 갱신 횟수, 과거 조회 경로. 10/6 첫 수집이 첫 실측이다.
이 화면은 상승률 상위 종목이 속한 테마만 보여 주는 선별 화면이다 — 테마 전체 구성이나 '더 나은 대장' 의 근거가 아니다(Codex 정정 유지).
