| 항목 | 내용 |
|---|---|
| 사용자 결정 | 2026-10-10 "GAS 09:00 트리거 추가" (허브 #15 결정 묶음) |
| 계기 | 깃허브 예약(09:10)이 10/8 에 5시간 44분 늦은 14:54 에 시작해 조회가 2번뿐이었다. 지금은 12:25 stockinfo7 실행에 연동돼 낮에야 시작한다 |

| 코드 쪽 | `hyeoks_research_daily.poll_deadline` — 한 실행의 조회는 시작 + 340분까지(깃허브 작업 한도 360분). 이 문서와 같은 커밋 |

## 하루를 두 실행으로 나눈다

깃허브 작업은 한 번에 최대 360분이다. 09:00 에 시작해 15:08 까지 한 번에 돌면 약 368분이라 한도에 걸린다.
한도에 걸리면 저장 전에 죽어 그날 원자료를 잃는다. 그래서 하루를 둘로 나눈다.

| 실행 | 발사 | 조회 구간 |
|---|---|---|
| 아침 | **GAS 09:00** (이 문서) | 09:0x ~ **12:15** (`until` 입력) |
| 오후 | GAS 12:25 stockinfo7 실행에 연동(`workflow_run`, 기존) | 12:2x ~ 15:08 |
| 백업 | 깃허브 예약 09:10·11:10·13:10 (기존) | 같은 그룹에서 대기. 15:08 이후 시작하면 아무것도 안 한다. 일찍 시작해도 340분에서 끊는다 |

- 같은 날 실행이 둘 이상이면 각 실행은 따로 기록하고, 분석 때 접수번호(뉴스는 일련번호)별 **가장 이른** 처음 본 시각을 쓴다. 사전 고정 §3 과 같다.
- 오후 실행의 DART 첫 조회는 전 거래일부터 다시 훑는다. 그래서 오전에 본 공시가 오후 기록에도 다시 나온다. 가장 이른 시각을 쓰므로 판단에는 문제가 없다.
- 한투 뉴스의 넘침 판정은 실행마다 첫 조회를 빼고 센다. 12:15~12:2x 사이 몇 분은 넘침으로 잡히지 않는다.

## GAS 코드 — `매크로.gs` 맨 끝에 붙이는 추가 블록

기존 함수는 바꾸지 않는다. 9/23 실적 블록과 같은 전역(`GITHUB_MASTER_TOKEN`·`GITHUB_OWNER`·`GITHUB_REPO`)을 쓴다.

```javascript
// -------------------------------------------------------------
// 🗞️📰 [2026-10-10 신규] DART 공시·한투 뉴스 아침 수집 발사 (09:00)
//    깃허브 예약(09:10)은 몇 시간씩 늦었다(10/8: 14:54 시작). 아침 수집은 GAS 가 쏜다.
//    ⚠️ 깃허브 작업은 최대 6시간 — 09:00~15:08 을 한 번에 돌면 넘친다.
//       아침 실행은 12:15 까지만 돌고, 오후는 12:25 stockinfo7 실행에 연동된 수집이 15:08 까지 맡는다.
//    휴장일은 수집기가 스스로 건너뛴다(달력 기준). 주말은 아래 방어막이 막는다.
// -------------------------------------------------------------
function triggerMaterialMorning(e) {
  // 하나가 실패해도 다른 하나는 쏜다. 실패는 끝에 모아서 던진다(GAS 실패 메일).
  var errors = [];
  ["dart_disclosures.yml", "kis_news.yml"].forEach(function (file) {
    try {
      dispatchWithInputs_(e, file, { "until": "12:15" });
    } catch (err) {
      errors.push(String(err));
    }
  });
  if (errors.length) throw new Error(errors.join(" | "));
}

function dispatchWithInputs_(e, file, inputs) {
  // 🛡️ 주말 방어막 (다른 트리거들과 같은 규칙 — 수동 실행은 통과)
  if (e && (new Date().getDay() === 0 || new Date().getDay() === 6)) return;
  if (!GITHUB_MASTER_TOKEN) throw new Error("GITHUB_MASTER_TOKEN 스크립트 속성이 비어 있다");

  var url = "https://api.github.com/repos/" + GITHUB_OWNER + "/" + GITHUB_REPO
          + "/actions/workflows/" + file + "/dispatches";
  var res = UrlFetchApp.fetch(url, {
    "method": "post",
    "contentType": "application/json",
    "headers": {
      "Authorization": "Bearer " + GITHUB_MASTER_TOKEN,
      "Accept": "application/vnd.github.v3+json"
    },
    "payload": JSON.stringify({ "ref": "main", "inputs": inputs }),
    "muteHttpExceptions": true
  });
  var code = res.getResponseCode();
  if (code !== 204) {
    throw new Error("🗞️ " + file + " 발사 실패 HTTP " + code + ": " + res.getContentText().slice(0, 200));
  }
  Logger.log("🗞️ " + file + " dispatch 완료 " + JSON.stringify(inputs));
}

// ⏰ 아침 재료 수집 트리거만 설치한다. 이 함수의 기존 트리거만 지우고 다시 만든다.
//    다른 트리거는 건드리지 않는다 — 여러 번 눌러도 중복되지 않는다.
function setupMaterialAlarms() {
  ScriptApp.getProjectTriggers().forEach(function (t) {
    if (t.getHandlerFunction() === "triggerMaterialMorning") ScriptApp.deleteTrigger(t);
  });
  ScriptApp.newTrigger("triggerMaterialMorning").timeBased().everyDays(1).atHour(9).nearMinute(0).create();
  SpreadsheetApp.getActiveSpreadsheet().toast("✅ DART·한투 뉴스 09:00 아침 수집 트리거 설치", "HYEOKS 시스템");
}
```

## 설정 순서

1. `매크로.gs` 맨 끝에 위 블록을 붙이고 저장한다.
2. **주말이나 휴장일에** 함수 선택 → `triggerMaterialMorning` → 실행. 수동 실행은 주말 방어막을 통과한다.
   Actions 탭에 `🗞️ OpenDART 공시 재료 수집` 과 `📰 한투 시황·공시 제목 수집` 이 방금 시각으로 뜬다.
   둘 다 "예정 거래일이 아니다 — 수집 생략" 으로 바로 끝나면 토큰·경로·입력이 맞다. 시장 API 는 부르지 않는다.
3. 함수 선택 → `setupMaterialAlarms` → 실행. 토스트 "DART·한투 뉴스 09:00 아침 수집 트리거 설치".
4. 왼쪽 시계 아이콘(트리거)에서 `triggerMaterialMorning` 한 줄이 생겼는지, 실패 알림이 "즉시" 인지 확인한다.

### ⚠️ `setupAllMasterAlarms()` 는 누르지 않는다

9/23 문서와 같은 이유다. 이 함수는 프로젝트 트리거를 전부 지우고 목록에 적힌 것만 다시 만든다.
