# 네이버 이전 대응 — Claude 전달

상태: 로컬 구현/검증 완료. main 직접 push 승인 대기이므로 운영 반영 완료가 아니다.
이전 산업리포트 변경 커밋도 아직 같은 로컬 브랜치에 있다.

## 변경

- 공통 읽기 전용 어댑터 `naver_sources.py` 추가. 표준 라이브러리만 사용.
  TLS 검증 유지, 12초 timeout, HTTP/JSON/필수필드 오류를 SourceError로 전달.
- 모닝 뉴스: 구 finance HTML에서 실제 응답을 확인한 MAINNEWS JSON으로 전환.
  중복 제목 제거. 빈 목록/실패를 '뉴스 없음'으로 숨기지 않고 경고와 원천 미확보 문구를 AI 입력에 전달.
- 모닝 종목 검색: 404인 /api/search/all 대신 ac.stock.naver.com/ac 사용.
  정확한 이름+6자리 코드가 유일할 때만 반환. 첫 유사 검색 결과를 임의 선택하지 않음.
- 컨센서스: 새 네이버 화면의 iframe으로 확인한 WiseReport 공개 경로 사용.
  페이지에서 sDT 기준일을 읽고 실제 화면의 요청 파라미터로 조회.
  flag=2, frq=1(분기), finGubun=IFRSL(연결).
  제공사 템플릿의 SALES/OP/NP ↔ 매출액/영업이익/당기순이익, **억원** 단위 확인.
  (E)만 수집, (A) 제외. 연결 기준/분기 라벨/중복 기간/필드/비유한 숫자 검사.
- 컨센서스 원천 실패가 한 종목이라도 있으면 해당 시트 갱신을 보류하고 실행 실패로 표시.
  DART 확정 실적 계산과는 분리. 확정 실적 저장은 기존 흐름을 유지한다.
- 성공 시 기존 컨센서스 A:G 헤더 확인 후 새로 확보된 종목만 교체하고
  미처리/추정치 없는 종목은 이전 값과 이전 갱신일을 유지한다.
  전체 clear 제거, update 후 실제 초과 범위만 A:G 정리. H열 이후는 건드리지 않는다.
- 의존 진단기에 실제 모닝 뉴스/정확 검색/분기 컨센서스 3개 검사를 추가했다.

## 검증

- 오프라인 unittest **180개 통과**: 기존 167개 + 신규 13개.
- 실제 조회: 정확 검색 삼성전자→005930, 주요뉴스 15건.
- 삼성전자/SK하이닉스/NAVER 각각 2026.09(E), 2026.12(E), 2027.03(E) 조회 확인.
  실제 값은 개인 참고자료로만 사용하며 본 문서/테스트 fixture에는 복제하지 않았다.
- 제공사 근거:
  https://stock.naver.com/domestic/stock/005930/info/consensus
  https://navercomp.wisereport.co.kr/v3/company/c1050001.aspx?cmp_cd=005930
- 실제 구글시트 쓰기, Gemini 호출, 텔레그램 발송, 운영 워크플로 실행은 하지 않았다.
  따라서 서비스계정 권한/러너 네트워크/시트 쓰기까지 종단간 인증한 것은 아니다.

## 남은 주의

- 새 컨센서스는 분기 연결만 지원한다. 과거 HTML 수집분의 연간/분기 혼합 또는 재무기준을
  이번 수정으로 소급 정정했다고 말하지 말 것. 미처리 종목의 구자료는 원래 날짜 그대로다.
- provider sDT는 조회 기준일이지 각 증권사의 추정치 작성시각이 아니다.
  현재 조회한 추정치를 과거 시점의 검증 입력으로 소급 사용하지 않는다.
- 브리핑은 뉴스 실패 시 경고를 포함하고 나머지 자료로 계속 작성한다.
  컨센서스 실패는 기존 시트를 보존하고 비정상 종료한다. 두 동작은 의도적으로 다르다.
- 기존 진단기의 구 HTML 실패 항목과 레거시 심각도 분류는 이번에 삭제하지 않았다.
  새 검사 성공만으로 전체 진단기가 초록이거나 모든 네이버 의존성이 복구됐다고 말하지 말 것.
- 스윙 선정 기준, 종베 15:05→익일 시가, DART V3 산식은 변경하지 않았다.
- main 직접 push는 앞선 권한 검토에서 거절됐으므로 명시적 승인 전 재시도하지 않는다.
