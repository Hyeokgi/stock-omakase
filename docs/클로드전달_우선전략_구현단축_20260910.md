# 클로드 전달: 세 전략 우선 구현과 일정 단축

2026-09-10. 사용자 요청: 리포트 단기·중기 스윙과 15:05 종베를 모두 유지하면서 구현 기간을 단축.
브랜치: `feat/priority-forward-20260910`. 기준은 main `8f5621c` 및 미병합 15:05 수정 `b2a519e`.
이 브랜치는 **앞선 15:05 어댑터 수정도 포함**하므로 병합 검토 시 함께 확인한다.

## 판단

6~10개월은 Q5 연구의 계획 예시에서 나온 기간이다. 세 전략의 개발 전체가 그 기간 동안
대기해야 한다고 설명한 것은 범위를 지나치게 넓힌 안내였다. 구현·자료 연결·모의운용을
먼저 진행하고 전략별 미래 검증은 병렬로 수행한다. 통계 기준을 낮추거나 실전 전환일을
확정하는 방식으로 단축하지 않는다. 효과가 없거나 자료가 계속 부족하면 실전 전환은 보류한다.

## 이번 실제 변경

1. 로드맵 상단에 사용자 우선순위를 반영하고 `우선전략_병렬구현계획_20260910.md`를 추가했다.
   Q5 완료/과거 386행 복원/장기·수급·웹앱 개편을 세 전략 모의운용의 선행 조건에서 분리했다.
2. `priority_trials.py`를 추가했다. 준비된 prospective(사전 기록) 입력으로 세 경로를
   독립 평가한다. 단기 신호+T5, 중기 신호+T10, 종베 신호일 15:05~다음 거래일 종가 기준선이다.
3. 정책 등록/선정/일자 기록/모의 체결 시각의 순서를 검사하고 버전 혼합을 막는다.
   장 종료 후 발행되는 리포트도 다음 거래일 시가 이전 기록이면 허용한다.
4. 종베 15:05를 다음 날 시가나 실제 캡처 15:02로 바꾸지 않는다. 정확한 진입 시점의
   모의 가격·상태가 없으면 그 거래를 차단한다. 기존 스냅샷 시각을 위장하지 않는다.
5. 무신호일과 기록 누락을 구분한다. 미성숙·진입 대기·청산 결측/불가를 구분하며
   모르는 손익을 0으로 채우거나 미성숙을 승률에 넣지 않는다.
6. 확보된 종료 거래의 비용 후 평균·중앙값·승률과 모든 거래 상태를 보존한다.
   다른 전략의 정책 미등록이 정상 전략의 집계 자체를 막지는 않는다.
7. 입력·결과·계산 소스·전체 해시를 비공개 로컬 실행 폴더에 보존한다.
   Git 무시 규칙과 입력 없는 오프라인 CI 테스트 workflow를 추가했다.

## 구현 완료가 아닌 부분

새 도구는 **오프라인 모의 거래 평가기**다. 기존 리포트/스냅샷과 자동 연결되거나 실제 주문이
나가는 상태는 아니다. 새 후보 선정 규칙, 핫 테마 대장 정의, 자료 수집 어댑터, 실체결
모니터, 거래정지 후 지연 청산 처리는 아직 연결/구현하지 않았다.

개별 거래 수익률을 계좌 수익률 또는 MDD로 부르지 않는다. 현금·중복 보유·테마 노출은
기존 계좌 모형과 별도 연결 검증이 필요하다. 대조군 대비·유의성·독립 재현도 구현하지 않았고,
모든 결과의 live_approved는 false다. 입력자의 출처/시각 주장을 해시만으로 인증하지 못한다.

기존 선정 프롬프트·점수 문턱·자동매매 설정·원장은 변경하지 않았다. 특히 중기 후보가 적다는
이유로 엔벨로프를 완화하지 않았다. 실계좌 손절/비중 설정을 새 기본값으로 강제하지 않았다.

## 테스트

신규 18개 + 기존 77개 = `unittest discover -s tests` 95개 통과.
어댑터·판정·타점 자체 검사도 통과. 핵심 신규 반례는 정확한 15:05, 야간 리포트 허용,
T5/T10 분리, 정책 혼합/사후 선정 차단, 다른 전략 결손 격리, 미성숙/미확인 청산,
무신호와 누락의 구분, 비용, 중복 종목, 비정상 가격 및 로컬 저장 완결성이다.
실데이터와 GitHub CI 원격 실행은 이번에 수행하지 않았다.

## 후속 작업 순서

1. 리포트 동결 원본에서 단기/중기 `policies`, `days`, `signals`를 만드는 연결기를 먼저 구현.
   현재까지 보고서 선정 당시 기록이 남은 구간만 쓰고 과거 마크를 미래 검증으로 소급 변환하지 않는다.
2. 15:05 종베는 선택 규칙과 후보 전체를 고정하고 주문 시점의 실제 호가/상태 수신과 다음 날
   청산 관측을 연결. 시점 오차 허용을 정하려면 결과를 보기 전에 별도 정책으로 등록한다.
3. 실제 하루 기록 대사 → 최소 T10 성숙 확인 → 자동 모의운용/누락 경보 순으로 검증.
   동시에 대조군과 현금/중복 위험을 연결하되 Q5 종료나 386행 복원을 기다리지 않는다.
4. 본격 자금 투입은 비용 후 성과·손실 꼬리·시점별 체결 품질·자금 한도·미사용 검증을 보고
   사용자와 별도 결정한다. 달력 날짜나 테스트 개수만으로 자동 승인하지 않는다.

조건부 개발 목표는 4~6주다. 10/5는 중간 점검이며 자료/접근/규칙 확정이 지연되면 목표도
달라진다. 수익성 입증 기간 또는 투자 시작 약속이 아니다. 자세한 입력 계약은
`docs/우선전략_모의평가기_사용법.md`에 있다.
