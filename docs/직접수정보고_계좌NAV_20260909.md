## 결론과 범위

계좌 산출기의 확인된 계산 오류와 실행·증거 보존 경로를 수정했다. **코드 수정과 합성 데이터 검증 완료**이지 실제 386행의 수익성 재검증 또는 운영 배포 완료가 아니다. 기존 `+6.58% / MDD 4.55%`는 올바른 계좌 실적의 근거로 사용하지 않는다. 원본 보고서는 삭제하지 않고 정정 대기 경고를 붙였다.

이번 구현은 연구용 고정 보유 가상 계좌 재구성에 한정한다. 운영 종목 선정·AI 프롬프트·시트·웹앱·기존 판정 규칙은 변경하지 않았다. 종베 조건 발굴은 별도 연구 설계로 문서화했으며, 실제 특징 탐색이나 손절·트레일링 계좌 비교를 완료했다고 주장하지 않는다.

원장 `진입일`은 신호일이고 `진입가(T+1시가)`가 실제 추적 진입 기준이다. 따라서 신호 다음 거래일 시가 진입, 신호+H 거래일 종가 청산을 적용했다. 이 계좌 모형은 당일 종가 매수 종베 전략을 대신 검증하지 않는다.

## 아직 검증하지 않았거나 구현하지 않은 부분

1. **실제 386행 재계산 미실행.** 빠짐없는 실제 거래일 달력·동일 조정 기준 일별 OHLC·신호 당시 테마 소속을 고정 입력으로 준비해야 한다. 원장에 현재 마크가 없는 행의 실제 구성도 이번 테스트로 확인된 것이 아니다.
2. **Drive 실제 연동 미실행.** 수동 workflow에는 별도 Secret `ACCOUNT_DRIVE_OAUTH`와 비공개 입력 파일/출력 폴더가 필요하다. 채팅의 Drive 연결이 Actions에 전달되지는 않는다. 서비스 계정은 개인 Drive 파일 소유가 불가능하므로 사용자 OAuth 경로를 명시했다. [Google 공식 제약](https://developers.google.com/workspace/drive/api/guides/about-shareddrives).
3. **일관된 수정주가 기반 가상 수량 모형.** 실제 분할·배당의 수량/현금 이벤트, 실제 주문·체결, 세금 구간별 변화는 구현하지 않았다. 미조정 주가와 혼합을 거부한다. 종가 MDD는 장중 위험의 완전 측정이 아니다.
4. **비중 제한은 신규 주문만 제약.** 시장 변동에 따른 사후 초과는 강제매도하지 않는다. 고정 주문 우선순위가 선택에 영향을 줄 수 있다. 기본 금액·비용은 연구 가정이며 추천 비중/실측 비용이 아니다.
5. **대조군은 아직 인과효과 검증 아님.** 동일 자본이어도 채널별 빈도와 보유기간이 다르다. 선정 능력 비교에는 진입일·보유기간·기회집합을 맞춘 대조군이 추가로 필요하다.
6. **손절/트레일링 비교와 종베 특징 분석기 미구현.** 기존 가격 모형의 정확성을 먼저 확보한 뒤 별도 정책 버전으로 구현해야 한다. 현재 결과에는 이 규칙들이 포함되지 않는다.
7. **새 정책 채택·통계적 우위 판정 미실행.** 10/5는 자료 품질과 가설 점검 시점으로 사용할 수 있으나 수익성 입증 기한은 아니다. 성과를 본 뒤 조건을 고른 구간과 이후 미사용 검증 구간을 분리해야 한다.

## 운영 전 순서

1. 사용법 문서 규격으로 비공개 고정 입력 준비 → 로컬 재계산 및 행 수 대사.
2. 실제 인증된 비공개 저장 경로에서 업로드·다시 읽기 검증 → 운영 전환 판단.
3. 전략과 동일한 진입일/보유기간을 갖는 비교군 및 청산 정책별 계좌 비교 추가.
4. 종베 연구에서는 당시 후보 전체(하락 사례 포함)를 고정하고 대장 선정 효과와 추가 조건 효과를 분리. 조건 1~2개로 시작하고 이후 미사용 날짜에서 검증.

기존 라이브 원장, 비밀키, 운영 선정 정책과 `main`은 이번 로컬 작업에서 변경하지 않았다. 새 수익률이나 승률은 입력 확보 후 별도 보고한다.
